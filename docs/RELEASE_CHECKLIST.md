# TrustVault Release Checklist

## Purpose

Use this checklist before releasing or promoting a milestone that affects the marketplace, assets, or public-facing experience.

---

## Release Verification

- [ ] TypeScript passes
- [ ] ESLint passes
- [ ] Production build passes
- [ ] No console errors are present in the browser
- [ ] Responsive testing is completed on desktop, tablet, and mobile
- [ ] Accessibility has been verified
- [ ] Images are optimised and correctly formatted
- [ ] Catalogue data has been validated
- [ ] Documentation is updated where relevant
- [ ] Lighthouse Performance, Accessibility, Best Practices, and SEO targets have been reviewed

---

## Notes

- This checklist should be completed before merging a milestone that changes UI, assets, or product data.
- If a release item fails, resolve it before sign-off.
- Documentation, assets, and product catalogue changes should remain aligned with the release state.
