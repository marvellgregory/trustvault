# Product Images

This directory contains production-ready product image assets for TrustVault.

Each category contains folders named using the canonical Product ID from the TrustVault Product Catalogue.

Example:

```text
public/images/products/

beauty/
    TV-BBW-000001/
        cover.webp
        1.webp
        2.webp
        3.webp

skincare/
    TV-SKN-000001/
        cover.webp
        1.webp
        2.webp
```

## Guidelines

- Never rename Product ID folders.
- Never rename image filenames.
- Always use the following image filenames:
  - cover.webp
  - 1.webp
  - 2.webp
  - 3.webp
- Product IDs must match the TrustVault Product Catalogue exactly.
- Product images are optimized in WebP format.
- Original source images remain in source-data/product-images.
- This folder contains only production-ready assets.
